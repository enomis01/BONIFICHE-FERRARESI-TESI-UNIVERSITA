# 🌿 Digitalizzazione e Rendicontazione ESG: Smart Farming in Bonifiche Ferraresi

Piattaforma web interattiva sviluppata nell'ambito del progetto di Tesi Magistrale in **Biologia della Sostenibilità** (Università degli Studi di Napoli Parthenope).

## 🚀 Panoramica del Progetto
Il progetto unisce le competenze ecologico-ambientali alle moderne tecnologie di frontend per digitalizzare e rendere interattivo il monitoraggio dei KPI di sostenibilità (ESG) e delle pratiche di Smart Farming del Gruppo **Bonifiche Ferraresi S.p.A.**

## ✨ Caratteristiche Principali
* **Design Responsive & Moderno:** Interfaccia ispirata ai portali corporate internazionali con effetto *Glassmorphism*.
* **Dashboard KPI Dinamica:** Contatori numerici animati tramite *IntersectionObserver* basati sui dati reali di bilancio.
* **Carosello 3D Interattivo:** Galleria multimediale avanzata per l'esplorazione dei focus tecnologici (droni, IoT, sub-irrigazione) con controlli direzionali e prospettiva 3D.
* **Eco Mode (Dark Mode):** Schema cromatico invertibile per la riduzione del consumo energetico dei display.
* **Bilinguismo Dinamico (IT/EN):** Selettore di lingua integrato in tempo reale senza ricarica della pagina.
* **Archivio ESG Pluriennale:** Sezione dedicata alla consultazione e al download dei report di sostenibilità storici (2023-2025).

## 🛠️ Tecnologie Utilizzate
* **HTML5 Semantico**
* **CSS3** (Custom Properties, Flexbox, Scroll-Snap, 3D Transforms)
* **Vanilla JavaScript (ES6+)** per la logica interattiva, i contatori e la traduzione SPA-style.
